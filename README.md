# Desmonte Lima - Transportes Luchito

Proyecto optimizado para GitHub Pages, campañas SEM y posicionamiento local.

## Tracking
Edita `assets/js/tracking-config.js` y reemplaza los IDs de GA4, Google Ads, Meta Pixel y TikTok Pixel.

## Dominio
El archivo CNAME está configurado para `desmontelima.com`.

## Importante
La galería es general para Lima Metropolitana. Las páginas por distrito usan contenido orientado a posicionamiento local, sin inventar fotos específicas cuando todavía no hay evidencia suficiente por zona.
